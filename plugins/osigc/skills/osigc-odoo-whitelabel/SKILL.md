# OSIGC · White-label

OSI Global vende **consultoría + sistema propio**, no software de terceros reempaquetado.
De cara al cliente, la plataforma es OSIGC; la fontanería interna no existe para él.
Esto protege el posicionamiento y el diferencial comercial.

## Dónde aplica
Toda superficie que pueda ver un cliente o tercero: copy web, emails, UI (labels,
botones, toasts), propuestas, **dosieres y manuales entregables** (aunque sean técnicos),
capturas, `alt`/`title`, metadatos y `<meta>`/SEO.

No aplica al código fuente ni a comentarios/documentación internos: ahí se nombra
Odoo, n8n, etc. con normalidad.

## Vocabulario de cara a cliente
Sustituye la marca real por el producto OSIGC:

| Interno (real) | De cara a cliente |
|---|---|
| Odoo / OpenERP | **plataforma OSIGC** / **ERP OSIGC** |
| CRM de Odoo | **CRM OSIGC** |
| n8n / automatizaciones | **motor de automatización OSIGC** |
| Mautic | **marketing automation OSIGC** |
| Chatwoot | **centro de comunicación OSIGC** |
| Postgres / infra | (no se menciona; habla de “tu plataforma”) |

## Prohibido en texto de cara a cliente
- **Odoo**, **OpenERP** y cualquier variante o guiño ("basado en Odoo", "ERP open").
- **"open source"**, "código abierto", "software libre" como descripción del producto.
- Stack interno: **n8n, Mautic, Chatwoot, Brevo, Postgres, Traefik, HestiaCP** y similares.

## Permitido nombrar (integraciones de confianza)
**Stripe** (pagos) y **Cal.com** (agenda) pueden citarse como integraciones, si aporta
credibilidad. No son fontanería a ocultar.

## Cómo revisar
1. Localiza nombres de tecnología y "open source" en el texto.
2. Reescribe con el vocabulario OSIGC (resultado/capacidad, no producto de terceros).
3. Si el original explicaba *cómo* está hecho por dentro, reorienta al *qué obtiene* el cliente.
4. Si detectas la fuga en un sitio, búscala en el resto del entregable y corrígela en todos.
